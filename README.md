# 2048 Game

A simple implementation of the famous **2048 puzzle game** built with **vanilla JavaScript, HTML, and CSS**.
The goal is to slide numbered tiles on a grid to combine them and create the **2048 tile**.

- 🎮 [Demo Link](https://your-demo-link.com)

## 🔗 Design Reference

- 🎨 [Original 2048 Inspiration](https://play2048.co/)

## 🛠️ Tech Stack

Core

- JavaScript (ES6+) – Game logic
- HTML5 – Structure
- CSS3 – Styling

Features

- Keyboard Events – Player controls
- Grid System – Dynamic board generation
- Local Storage – Save and load high scores

Development & Deployment

- ESLint + Prettier – Code quality & formatting
- gh-pages – Deployment

## ⚙️ Installation & Setup

- Clone the repository:

  - git clone https://github.com/ogchy/portfolio_js_2048_game

  - cd portfolio_js_2048_game


- Install dependencies:

  - npm install
    or
    yarn install


- Run the project locally:

  - npm start
    or
    yarn start

🎮 Classic 2048 gameplay
